## ✨ What is this?

A tabular-ML classifier that predicts hypertension risk from routine patient data (age, BMI, salt intake, sleep, smoking, family history…). Train from the CLI **or** over HTTP, then serve single-patient predictions from the same pipeline — imputation, scaling, and one-hot encoding bundled inside, so train and serve can never disagree.

| Capability | Details |
|---|---|
| 🏆 Auto model selection | LogisticRegression vs RandomForest vs GradientBoosting — best CV score wins |
| 🔬 Honest evaluation | 5-fold stratified CV + 20% stratified holdout (accuracy, F1, confusion matrix, ROC AUC) |
| 🧹 Leak-proof pipeline | Median/mode imputation → StandardScaler → OneHot inside one `Pipeline` object |
| 🚀 Dual interface | `train.py` for the terminal, `POST /train` + `POST /predict` over HTTP |
| 💾 One-file artifact | Entire preprocessing + model saved as `best_model.joblib` (~60 KB) |

## 📊 Results (reproduced)

| Model | CV mean accuracy | CV std |
|---|---|---|
| GradientBoosting 🏆 | **99.04%** | 0.29% |
| RandomForest | 94.71% | 0.66% |
| LogisticRegression | 87.41% | 1.42% |

Holdout (397 patients): **accuracy 97.73% · macro F1 0.98 · ROC AUC 0.9982**

## ⚙️ How it works

```
hypertension_dataset.csv (1985 rows × 11 cols)
      ↓
5 numeric (median → scale) + 5 categorical (mode → one-hot) → Has_Hypertension
      ↓
Stratified 5-fold CV × 3 models → winner refit on 80% → tested on 20%
      ↓
best_model.joblib → POST /predict { patient JSON } → { prediction, probability }
```

## 🚀 Quickstart

```bash
cd Hypertension-model
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
python train.py
uvicorn app:app --reload
```

Train (CLI):

```bash
python train.py
```

Predict (server runs at http://127.0.0.1:8000 by default):

```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d "{\"Age\":69,\"Salt_Intake\":8.0,\"Stress_Score\":9,\"Sleep_Duration\":6.4,\"BMI\":25.8,\"BP_History\":\"Normal\",\"Medication\":\"None\",\"Family_History\":\"Yes\",\"Exercise_Level\":\"Low\",\"Smoking_Status\":\"Non-Smoker\"}"
```

Interactive docs at **http://127.0.0.1:8000/docs** 🎉

## 🔍 Sample output

```json
{
  "prediction": "Yes",
  "probability": 0.8373
}
```

Plus `GET /model` (which estimator is loaded) and `POST /train` (retrain over HTTP with custom `target_col`, `cv_splits`, `test_size`).

## 🛠️ Tech stack

| Layer | Tech | Why |
|---|---|---|
| Model | scikit-learn (GBM/RF/LR) | Right-sized for 2k-row tabular data — no GPU needed |
| API | FastAPI + Pydantic | Typed patient schema, auto OpenAPI docs |
| Data | pandas + joblib | CSV in, compressed pipeline out |

## 📁 Project structure

```

├── train.py                # CLI training: CV → select best → evaluate → save

├── training_summary.json   # Best model + test accuracy (regenerated)
```
